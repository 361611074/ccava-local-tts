## 一、准备环境

### 1. 装 Python

到 [python.org](https://www.python.org/downloads/) 下载 **3.9 或更高版本**（推荐 3.12），安装时**勾上 "Add Python to PATH"**。

装完验证：

```bat
python -V
```

能打印版本号就行。如果提示找不到命令，重开一个命令行窗口再试。

### 2. 装依赖

```bat
pip install edge-tts
```

只有想在桌面自动建快捷方式时，才需要再装一个（纯 Python 实现，很小）：

```bat
pip install pylnk3
```

国内网络慢的话换镜像：

```bat
pip install edge-tts -i https://mirrors.aliyun.com/pypi/simple/
```

除此之外全是 Python 标准库，不用装别的。

## 三、跑起来

```bat
python tts_server.py
```

会自动打开浏览器显示状态页。看到蓝色卡片写着「在线音色服务运行中」就成了。

手动验证接口：

```bat
curl http://127.0.0.1:5210/ping
curl http://127.0.0.1:5210/voices
```

`/voices` 应该返回一长串音色。想直接听一耳朵：

```bat
curl -o test.mp3 "http://127.0.0.1:5210/tts?text=你好，这是测试&voice=zh-CN-XiaoxiaoNeural"
```

### 常用参数

```bat
python tts_server.py --status              :: 服务在跑就返回 0
```

## 四、接到网页

网页那边需要一段适配代码（`tts-bridge.js`），作用是把服务提供的音色混进 `speechSynthesis.getVoices()`，并在朗读时改用服务合成的音频。

核心思路：

```js
// 1. 拉音色列表
fetch('http://127.0.0.1:5210/voices')
  .then(r => r.json())
  .then(d => {
    // 2. 包成 SpeechSynthesisVoice 的样子塞进 getVoices()
    // 3. 接管 speak()，虚拟音色走 Audio 播放，原生音色照旧
  });
```

有两个坑必须处理，否则跑不通：

**坑一：`SpeechSynthesisUtterance.voice` 的类型检查**

原生 setter 只接受真正的 `SpeechSynthesisVoice`，普通对象和 `Proxy` 都会被拒：

```
Failed to convert value to 'SpeechSynthesisVoice'
```

解法是直接接管这个属性：

```js
var desc = Object.getOwnPropertyDescriptor(SpeechSynthesisUtterance.prototype, 'voice');
Object.defineProperty(SpeechSynthesisUtterance.prototype, 'voice', {
  configurable: true,
  get: function () { return this.__ttsVoice || (desc.get && desc.get.call(this)); },
  set: function (v) {
    if (v && v.__edge) { this.__ttsVoice = v; return; }   // 虚拟音色存自定义字段
    this.__ttsVoice = null;
    if (desc.set) desc.set.call(this, v);
  }
});
```

**坑二：浏览器的本地网络访问限制**

Chrome 138+ 起，公网页面请求 `127.0.0.1` 要走 Private Network Access 预检。服务端必须回这几个头，否则请求在浏览器侧就被拦掉，服务端连日志都看不到：

```
Access-Control-Allow-Origin: *
Access-Control-Allow-Private-Network: true
```

OPTIONS 预检也要正常回 204。`tts_server.py` 里已经处理好了。

**坑三（播放层面的）：分段播放要防止叠音**

每段用独立 `Audio` 对象播放，切段前必须先彻底停掉上一段，否则上一段出错时 `onerror` 和 `onended` 会双触发，两段声音叠在一起响：

```js
function stopAudio() {
  var a = state.audio;
  state.audio = null;
  if (!a) return;
  try { a.onended = null; a.onerror = null; a.pause();
        a.removeAttribute('src'); a.load(); } catch (e) {}
}
```

再配一个自增序号，异步回调里先比对序号，过期直接丢弃。

## 五、打包成 exe（可选）

想让不懂 Python 的人也能用，可以打包成单文件 exe：

```bat
pip install pyinstaller
```

```bat
pyinstaller --onefile --noconsole --name TTS-Server ^
  --icon=tts.ico ^
  --version-file=version_info.txt ^
  --collect-data certifi ^
  --hidden-import aiohttp --hidden-import multidict --hidden-import yarl ^
  --hidden-import frozenlist --hidden-import aiosignal --hidden-import attrs ^
  --hidden-import pylnk3 ^
  --clean --noconfirm tts_server.py
```

产物在 `dist\TTS-Server.exe`，约 10 MB。

几个要点：

- **必须 `--collect-data certifi`**，否则 SSL 证书找不到，所有请求失败
- `--noconsole` 后 `sys.stdout` 是 `None`，代码里所有 `print` 都要判空，否则一启动就崩
- onefile 模式运行起来是**两个进程**（bootloader + 真身），`taskkill /im` 能一起杀掉
- `--version-file` 让 exe 右键属性里显示作者和网址

版本信息文件 `version_info.txt` 长这样：


## 六、常见问题

**Q：`pip install edge-tts` 报找不到版本**
A：Python 版本太老（3.8 及以下）。升到 3.9+。

**Q：状态页能打开，但网页里音色没变**
A：刷新网页（Ctrl+F5）。还不行就检查浏览器控制台有没有 `Failed to fetch`——那多半是本地网络权限被拦，见「坑二」。也可能是服务没在跑，先看任务管理器里有没有 `TTS-Server.exe`。

**Q：朗读报 500**
A：看 `server.log`。最常见的原因是网络不通，或者 edge-tts 版本太旧被微软改了协议——`pip install -U edge-tts` 通常就好了。

**Q：端口 5210 被占用**
A：改 `config.json` 里的 `port`，同时把网页适配代码里的 `API` 常量一起改掉。

**Q：会消耗很多流量吗**
A：不经过你的服务器，本机直连微软，不花你一分钱。每段朗读大概几十 KB。

**Q：能装在服务器上给别人用吗**
A：技术上可以，但要想清楚：所有请求会从同一个 IP 出去，容易被微软限流；而且要考虑带宽和缓存。这个项目定位是**本地服务**，不建议做成公网接口。
