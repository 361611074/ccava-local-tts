# 在线音色本地服务

> 漫步白月光 · [https://www.ccava.net/](https://www.ccava.net/)

浏览器自带的朗读功能（`speechSynthesis`）只能读系统里注册的那几个语音。Windows 中文系统通常只有 1~4 个，听起来很单调。

这个小服务在本机起一个 HTTP 接口，把微软 Edge 的在线语音合成接进网页。装完之后，网页的语音下拉里会多出十几个中文音色——晓晓、云希、晓北、晓妮这些——选中就能读。

所有音频都在你自己的电脑上完成合成，服务只监听 `127.0.0.1`，局域网和公网都访问不到。

---

## 音色

14 个中文音色，全部免费、免密钥、无需注册：

晓晓、晓伊、云健、云希、云夏、云扬、晓北（东北话）、晓妮（陕西话）、曉佳 / 曉曼 / 雲龍（粤语）、曉臻 / 曉雨 / 雲哲（台湾）

实际数量取决于微软那边当前开放的列表，`/voices` 接口返回什么就是什么。

## 接口

服务就四个端点，都是 GET：

| 路径 | 说明 |
|---|---|
| `/ping` | 健康检查，返回 `{"ok":true,"port":5210,"engine":"edge"}` |
| `/voices` | 音色列表 |
| `/tts?text=&voice=&rate=&pitch=&volume=` | 合成，直接返回 mp3 字节流 |
| `/` | 状态页，浏览器打开就能确认服务活着 |

`rate` / `pitch` / `volume` 用 `+0%` / `+0Hz` 这种带符号格式，和 edge-tts 的参数一致。

单次请求文本上限 1200 字。网页端为了播放更连贯、失败重试代价更小，实际按 140 字一段切分请求。

## 目录

```
LocalTTS/
├── tts_server.py        主服务
├── config.json          你的配置（改端口就在这里）
├── config.example.json  配置模板
└── server.log           运行日志，超 1MB 自动轮转
```

服务打包成 exe 后，`config.json` 放在 exe 同目录。

---

## 命令行参数

| 参数 | 作用 |
|---|---|
| 无参数 | 启动服务并打开状态页 |
| `--autostart` | 静默启动（开机自启用的就是这个） |
| `--status` | 服务在跑返回 0，否则返回 1 |
| `--install-autostart` | 写入 `HKCU\...\Run`，开机自动启动 |
| `--remove-autostart` | 删除自启项 |
| `--check-autostart` | 已设自启返回 0 |
| `--install-shortcut` | 在桌面创建「在线音色服务」快捷方式 |
| `--remove-shortcut` | 删除桌面快捷方式 |

## 说明

- 只监听 `127.0.0.1`，不接收外部连接
- 不收集任何数据，日志只有合成记录（音色、字数、耗时）
- 走的是 Edge 浏览器的朗读接口，非官方 API，微软哪天改了协议可能就失效，届时升级 `edge-tts` 库通常能恢复
- 不需要任何密钥，不产生任何费用
